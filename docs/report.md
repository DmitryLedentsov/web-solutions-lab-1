# Ход работы и отладка

## Ход работы

1. Создан репозиторий и структура проекта.
2. Зафиксированы версии зависимостей в `requirements.txt`.
3. Настроен MkDocs с темой Material.
4. Добавлен исходный CSV с повторными измерениями.
5. Реализован `scripts/generate.py`, формирующий таблицу и график.
6. В генератор добавлено кэширование по содержимому данных, кода и зависимостей.
7. Добавлена строгая сборка `mkdocs build --strict`.
8. Настроен GitHub Actions для проверки, сборки и публикации GitHub Pages.

## Отладка

### Ошибка 1. Репозиторий не имел ни одного коммита

**Ошибка:** запрос содержимого пустого репозитория через GitHub API возвращал `404 This repository is empty`.

**Гипотеза:** default branch указана как `master`, но Git-ссылка ещё не существует без первого коммита.

**Проверка:** метаданные репозитория показали размер 0 и отсутствие содержимого.

**Решение:** создан первый файл `README.md`, после чего ветка `master` была инициализирована.

### Ошибка 2. Строгая сборка обнаружила битую ссылку

**Ошибка:** `WARNING - Doc file 'index.md' contains a link 'missing.md', but the target is not found among documentation files.` Затем MkDocs завершился сообщением `Aborted with 1 warnings in strict mode!`.

**Гипотеза:** ссылка ведёт на файл, которого нет в `docs/`, а режим `--strict` превращает предупреждение в ошибку.

**Проверка:** в логе GitHub Actions шаг `Strict MkDocs build` завершился с exit code 1, остальные предыдущие шаги были успешными.

**Решение:** удалена тестовая ссылка на `missing.md`. Это подтверждает, что strict-сборка действительно блокирует публикацию сайта с битой внутренней ссылкой.

### Ошибка 3

Будет заполнена по результатам контрольного CI-запуска.

## Вывод

Для небольших исследовательских проектов подходит связка Python + MkDocs: расчёты выполняются отдельным скриптом, а генератор сайта остаётся простым и отвечает только за публикацию Markdown и статических артефактов. Если вычисления становятся тяжёлыми или требуют GPU, их целесообразно вынести из CI и публиковать заранее рассчитанные артефакты с метаданными версии.
