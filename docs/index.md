# Публикация результатов исследования

Лабораторная работа посвящена публикации результатов вычислительного эксперимента с помощью генератора статических сайтов **MkDocs** и автоматической сборки в GitHub Actions.

## Что реализовано

- сайт на MkDocs с темой Material;
- исследовательское задание **T2** — анализ конвейера «эксперимент → артефакт → страница»;
- практическое задание **P3** — воспроизводимый конвейер «данные → результат → сайт»;
- генерация таблицы и графика из CSV с помощью Python;
- кэширование неизменившихся результатов;
- метки версии: commit, дата сборки и SHA-256 набора данных;
- строгая сборка `mkdocs build --strict`;
- автоматическая публикация на GitHub Pages.

## Выбранный стек

| Компонент | Инструмент |
|---|---|
| Генератор сайта | MkDocs 1.6.1 |
| Тема | Material for MkDocs 9.7.7 |
| Расчёты | Python + pandas |
| Графики | matplotlib |
| CI/CD | GitHub Actions |
| Публикация | GitHub Pages |

MkDocs выбран как наиболее простой вариант для этой работы: содержимое сайта хранится в Markdown, конфигурация небольшая, а сборка сводится к одной команде.
